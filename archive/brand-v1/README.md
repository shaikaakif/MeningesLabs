# Archive: MENINGES LABS brand v1

These files are retained for reference only. They represent the previous
burgundy/brick-red identity and are not part of the current approved brand
system. Nothing here should be used in live pages, campaigns or new material.

## Current brand system

- `docs/brand/` — approved brand kit, implementation brief and visual addendum.
- `public/brand-assets/` — current orange/cream logo family, monogram,
  app icons, favicon, social preview and founder portrait.
- `MeningesLabs Rebrand/` — original supplied artwork used to derive the
  production assets.

## What is archived here

- `docs/` — the v1 brand kit and the v1 micro-animation library.
- `logos/` — v1 primary lockup, descriptor lockup and ML monogram masters.
- `images/` — v1 logo variants, old favicon, old founder photo and the
  previous social artwork.
- `video/` — the previous brand advert and its poster.

Older size-specific derivatives from the retired `meninges-labs-brand-assets/`
folder are not duplicated here. They remain available in git history and were
replaced by the generated files in `public/brand-assets/`.
