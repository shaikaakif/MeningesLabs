# MENINGES LABS website

Next.js App Router site. Install dependencies with `npm install`, then run `npm run dev`.

The 12 core pages share one route template in `app/[slug]/page.tsx`. FAQ content lives in `app/content.ts`; the full set is on Services, with focused groups on service pages and a shorter set on Contact.

The display face uses locally hosted Cormorant Garamond, with a Canela-first font stack for a later licensed integration. Manrope and IBM Plex Mono are bundled locally. Update `socialLinks` in `app/content.ts` when social destinations change.
