# MENINGES LABS — LOGO ASSET PACKAGE

## Included identity
- Primary horizontal logo: ML geometric monogram + MENINGES LABS, without descriptor.
- Descriptor lockup: ML geometric monogram + MENINGES LABS + DIGITAL GROWTH & INTELLIGENCE.
- Standalone symbol: ML geometric monogram.
- App icons: standalone monogram on Papaya Whip background, exported in common sizes.
- Favicon: multi-resolution ICO.

## Brand colours
- Deep Pomegranate: #780000
- Papaya Whip: #FDF0D5

## File map
- `01-primary-logo/`: transparent PNG and WebP horizontal logo exports.
- `02-logo-with-descriptor/`: transparent PNG and WebP descriptor lockup exports.
- `03-symbol/`: transparent standalone symbol exports.
- `04-app-icons/`: square app icons, JPG variants and favicon.ico.
- `05-guidelines/`: this package's quick-use guidance.

## Recommended usage
- Website header: primary horizontal logo, typically 240–360 CSS px wide.
- Footer / formal company lockup: descriptor version when space permits.
- App tile / social avatar: square app icon.
- Favicon: `favicon.ico`; use 32×32 or 48×48 PNG as an additional modern favicon.
- On dark backgrounds: use a separately approved reversed white logo. Do not place this burgundy-on-cream version directly on dark backgrounds.

## Important production note
These are cleaned, resized raster exports derived from the approved generated logo concepts. The transparent cutout and recolouring are automated, so inspect small sizes and edge quality before production. The supplied artwork is not a manually redrawn, mathematically exact vector master. For a final professional identity system, commission or create a precise SVG/PDF vector trace and verify the wordmark font and kerning.
